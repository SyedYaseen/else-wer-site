else-wer is a self-hosted audiobook server with a fast, installable PWA player. You run it on your own hardware — a Raspberry Pi, an old laptop, a home server, a small VPS — and you keep your library and your data.

## Where to start

- **New here?** Start with [Quick start](/docs/quickstart/) — the fastest way to get else-wer running with Docker.
- **Want offline playback on iPhone/iPad?** Read [iOS offline limitations](/docs/ios-offline-limitations/) first, then [HTTPS with DuckDNS](/docs/https-duckdns/).
- **Want to reach your library away from home?** See [Remote access with WireGuard](/docs/wireguard-remote-access/).
- **Questions about cost, data, or hardware?** Check the [FAQ](/docs/faq/).

- **Which app should I use?** See [Apps](/docs/apps/): the web app is free, Android has a native app.

The else-wer server is free for personal use (source-available, [PolyForm Strict](https://polyformproject.org/licenses/strict/1.0.0/)). If it's useful to you, consider [supporting the project](/#support).
